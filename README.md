# 📚 BookShelf – Personal Library Management System

## 📝 Opis projektu
BookShelf to aplikacja umożliwiająca użytkownikom zarządzanie własną biblioteką książek. System pozwala na dodawanie książek, przeglądanie katalogu, wyszukiwanie pozycji oraz śledzenie postępów w czytaniu.

## 🎯 Cel projektu
Celem projektu jest stworzenie aplikacji ułatwiającej organizację prywatnej kolekcji książek i zarządzanie informacjami o przeczytanych oraz planowanych lekturach.

## ✨ Główne funkcjonalności
* Dodawanie, edytowanie i usuwanie książek.
* Wyświetlanie katalogu książek.
* Wyszukiwanie książek według tytułu i autora.
* Kategoryzowanie książek według gatunku.
* Śledzenie statusu czytania.
* Dodawanie ocen i prywatnych notatek.
